# Sunvale（晴谷）

一个用 [MyGo](https://github.com/egoist/mygo) 的**纯原生 UI** 实现的文件管理器，外观与排版完整对齐 Windows 11 文件资源管理器。界面组件与单色图标基于 [Onevra](https://github.com/oneo-me/onevra) 组件库（内嵌 Lucide 图标集），彩色文件/文件夹/盘符图标由 Go 在 GPU 上自绘。

没有 HTML、没有 WebView、没有 cgo——整个界面由 Go 绘制。

当前版本 **0.1.4**（`mygo.json`），三平台安装包由 GitHub Actions 在打 tag 时构建。

> 目录名仍为 `WinExplorer`（`/Users/mcx/Documents/OpenSpring/WinExplorer`），项目与可执行文件已更名为 **sunvale / 晴谷**。

## 下载与安装

| 平台 | 文件 | 安装方式 |
| --- | --- | --- |
| macOS | `Sunvale.<版本>.dmg`（darwin/universal） | 打开 dmg，把 Sunvale 拖进「应用程序」 |
| Windows | `Sunvale.Setup.<版本>.amd64.exe` / `.arm64.exe` | 用户级安装到 `%LOCALAPPDATA%\Programs\Sunvale`，无需管理员；支持 `/S` 静默安装 |
| Linux | `sunvale_<版本>_amd64.deb`、`sunvale-<版本>-linux-<arch>.tar.gz`、`install.sh` | `sudo apt install ./sunvale_*.deb`；或用 `install.sh` 免 root 装进 `~/.local`（`curl -fsSL https://github.com/mcxen/WinExplorer/releases/latest/download/install.sh \| sh`，可带 `--uninstall`） |

从 [Releases](https://github.com/mcxen/WinExplorer/releases) 下载。Windows 安装包带开始菜单项、控制面板卸载项、压缩格式文件关联与 URL scheme；Linux 的 `install.sh` 对 amd64/arm64 通用（运行时按 `uname` 选目标）。也可以直接用源码运行，见下一节。

同一个 release 里还有 `update-<平台>.json` 清单、签名的更新包与 `.delta` 增量包，供应用内置的自动更新使用（见「自动更新」）。

## 性能与启动

- 首帧约 **150ms**（`WINEXPLORER_TIMING=1` 启动可在日志看到 `启动：…后第一帧`）。
- 打开方式注册表（扫描 `/Applications` 与 `/System/Applications` 下每个应用的 `Info.plist`，plutil 八路并发）与画廊的 `~/Pictures` 遍历都改为**惰性**：前者在第一次打开「打开方式」菜单时启动（`ensureOpenWithScan` 一次性护栏），后者在第一次进入画廊页时启动——启动时刻两者零开销、不再抢最紧张的启动 CPU。

## 运行

需要 Go 1.27 或更高版本（MyGo 的要求）。

```bash
cd /Users/mcx/Documents/OpenSpring/WinExplorer
go run .
```

若本机 Go 低于 1.27，但 `GOTOOLCHAIN` 能取到新版：

```bash
GOTOOLCHAIN=go1.27.2 go run .
```

构建单文件二进制：

```bash
go build -o sunvale .
```

## 界面布局

从上到下，对齐 Windows 11 资源管理器：

1. **标题栏（标签条内嵌）** —— 无边框窗口，标签条与最小化/最大化/关闭按钮共用一行；标题栏可拖动移动窗口、双击最大化。每个打开的目录一个标签，当前标签高亮，标签带关闭按钮，`+` 新建标签，右键标签弹出标签菜单。
2. **命令栏** —— `新建▾ | 剪切 复制 粘贴 重命名 分享 删除 | 排序▾ 查看▾ …`：中间一组为纯图标按钮（悬停出提示），`新建`/`排序`/`查看` 为带图标与下箭头的分割按钮，行尾 `…` 打开更多菜单（预览窗格开关、设置）。
3. **地址导航行** —— 后退、前进、向上，可点击的面包屑地址栏（点击空白处或编辑按钮切到路径输入），以及搜索框（占位符“搜索”）。
4. **主体** —— 左侧 Windows 11 导航树（主文件夹，插件页（画廊），**快速访问**，最近位置，**「此电脑」卷列表可逐级展开成文件树**——卷下面按需读取子文件夹，并自动展开到当前文件夹、把当前行滚入可视区，展开后还有磁盘健康与回收站；可拖动调整宽度 180–420）；中间文件区；右侧预览窗格（`Alt+P` 切换，可拖动 220–460）。
5. **状态栏** —— 项目数量、选中数量与体积、搜索状态，以及当前视图模式。操作结果（删除/移动/复制/重命名/压缩/解压/清理 .DS_Store…）同时以 **toast** 弹出：有可撤销操作的带「撤销」按钮（一键等同 `Ctrl+Z`），其余为普通提示。

外观上采用 Windows 11 的**材质与悬浮窗**语言（`glass.go`）：窗口带系统背景材质（Windows 11 的 Mica/亚克力，macOS 的 under-window 材质），标签栏、命令栏、地址行、侧边栏与状态栏不绘背景、让材质透出，文件列表保持不透光面层；不提供材质的平台（旧版 Windows、Linux）回退为主题色。各对话框（设置、属性、批量重命名、快速预览、重复文件、占用可视化、扩展编辑）为**磨砂玻璃悬浮面板**：圆角 12、大半径投影、暗化背景、上浮淡入入场（`ui.DialogBase` + `glass.Glass`）。

## 功能

**标签页**
新建（`Ctrl+T`）、关闭（`Ctrl+W`）、切换（点选 / `Ctrl+Tab` / `Ctrl+Shift+Tab` / `Ctrl+1..9`）；每个标签独立的导航历史、列表、选择、搜索与重命名状态。`Ctrl+N` 打开新窗口：每个窗口一个独立 App（标签页、撤销栈、应用内剪贴板互不干扰，同资源管理器），但快速访问固定、最近文件与回收站还原日志共享同一份持久化状态；窗口关闭时停掉其预览的音频并注销。标签右键菜单：复制标签页、关闭标签页、关闭其他标签页、关闭右侧标签页。把文件拖到标签上即移动到该标签所在文件夹。

**导航**
双击进入文件夹、`Enter` 打开、面包屑任意层级跳转、地址栏直输路径（`此电脑` 可回到此电脑页；输入文件路径则打开它所在的文件夹并选中该文件、滚到那一行）、前进/后退/向上（回到上一层时选中刚离开的文件夹并滚到它）、刷新（`F5`）；卷根或 `/` 向上回到“此电脑”。删除、复制、粘贴后列表就地更新，滚动位置保持不变，不会弹回最上面；新建和重命名会把新行滚进可视区。

左侧导航树里，「此电脑」是一棵**文件树**：卷行左侧的箭头逐级展开子文件夹，只在展开时读那一层目录（结果缓存，`F5` 与当前目录重载会失效重读），只列文件夹、按名称排序、尊重「隐藏的项目」，指向文件夹的符号链接也算文件夹；点行即导航，箭头只展开不导航，右键菜单与拖放（拖文件到行上即移动过去）和别处一致。侧边栏里的文件夹、固定项和最近位置本身也能拖：拖到别的文件夹是移动（按住 `Cmd/Ctrl` 为复制），拖到「快速访问」标题上则把文件或文件夹固定在那里，原件不动。拖到某一条已经固定的文件夹上仍然是移进那个文件夹，不会再固定一次。这棵树**跟随当前标签**：每次导航——前进/后退、面包屑、地址栏、搜索结果跳转、切换标签——都会展开当前文件夹的各级父目录、把它的行标为选中并滚入可视区，跟资源管理器的「展开到当前文件夹」一样（区别是这里没有开关，始终如此）。展开状态只活在当前窗口里，不写进状态文件；当前文件夹自身不会被自动展开（也与资源管理器一致）。

**选择**
单击、`Cmd/Ctrl+单击` 多选、`Shift+单击` 范围选、`Cmd/Ctrl+A` 全选；`↑`/`↓` 按行移动选择（图标视图与画廊里 `←`/`→` 横向移动），`Home`/`End` 到首尾，`PageUp`/`PageDown` 按一屏，`Shift+` 与方向键组合从锚点扩展——移到的行会自动滚入可视区，到列表两端即停。空白处按住左键拖动可**圈选**：框触碰到的行/磁贴即被选中（详情、列表、图标与画廊视图；侧边栏、主页、`此电脑` 卷行和回收站不支持），拖动中实时更新，`Shift` 追加、`Ctrl/Cmd` 反选（详见 `docs/marquee-selection.md`）。选择按标签独立，剪贴板为应用级（跨标签复制/粘贴可用）。

**视图与排序**
详细信息、列表、小/中/大/超大图标六种视图；按名称/修改日期/类型/大小排序，升序降序；点击列头切换排序。详细信息视图的列宽可调：列头右缘的拖拽手柄改写该列宽度（名称列默认随窗口伸展，拖动后固定；双击手柄恢复默认），下限保证表头可读，宽度持久化在设置里，对所有窗口生效。`查看` 菜单还提供**紧凑视图**（行距 30→22）、**放大图标 / 缩小图标**（七档、最大 4×，故超大图标可达 384 像素；`Cmd/Ctrl+Shift+=` / `-`，在详细信息或列表中按一次即切到图标视图）、**显示 > 文件扩展名**（关闭时隐藏已知扩展名，同资源管理器默认）、**显示 > 隐藏的项目**。

**媒体缩略图与文件夹封面**
中等图标及以上的图标视图不再只画文件类型图标：图片与视频直接显示自身画面——图片走内置解码器，HEIC/TIFF/AVIF 交给 Quick Look，视频用 `ffmpeg` 抽帧并叠加播放角标；**含图片或视频的文件夹仍是一只文件夹**——标签页、金色描边、圆角都在，其中最多 4 个媒体填在文件夹的正面板里（1 张铺满、2 张左右分栏、3 张左一右二、4 张 2×2，与资源管理器一致），边框不薄于 2 DIP，因此中等图标（48 像素）下也不会退化成一张裸拼图。封面按正面板的宽高比拼图，贴进面板时不再二次裁切。解码在后台以 4 路并发进行、按 LRU 缓存（64 MB 预算），放大跨过一档时按更大尺寸重解，`F5` 刷新清空缓存重新读取。详情/列表视图的 16 像素图标仍用自绘图标，既省解码也更清楚。

**分组依据**
`查看 > 分组依据`（无/名称/修改日期/类型/大小），四种视图都插入组头（组名 + 数量）：名称按首字母、日期按 今天/昨天/本周/上周/更早、大小按 空/小于 100 KB/小于 1 MB/中/大/巨大、类型按文件类型。

**文件夹大小**
详细信息视图的「大小」列对文件夹也显示体积。统计在后台 goroutine 中进行——每文件夹一次有界遍历（30 秒超时、25 万节点上限，跳过符号链接、计入隐藏文件），文件列表永不阻塞，统计完成前显示「…」；按大小排序与分组对文件夹同样生效，状态栏的选中合计也计入文件夹体积。结果缓存在内存（8192 条）与磁盘 `sunvale/sizes.json`（4096 条、最旧先淘汰，防抖 5 秒落盘、退出时落盘）：再次打开同一文件夹直接显示缓存值，仅当文件夹自身修改时间与缓存记录不一致时才自动重算。右键「刷新统计」（空白处对当前文件夹、文件夹行对该文件夹）强制重算其子树体积，只局部更新大小列、不整页刷新。统计不依赖窗口可见，最小化到托盘期间照常进行。

**文件操作**
新建文件夹、新建文本文档、内联重命名（`F2`，单选）、**批量重命名**、复制/剪切/粘贴（Windows 风格 `名称 - 副本` 命名）、删除（移入 `~/.Trash`）、永久删除、复制为路径（系统剪贴板）、在终端中打开、属性（打开属性对话框，见下）。

**批量重命名**
多选时 `F2`、命令栏「重命名」或右键「重命名」打开对话框，单选仍走内联重命名。三种模式（对话框顶部切换）：**模板**（占位符 `{name}` 完整原名、`{stem}` 去扩展名、`{ext}` 不带点、`{n}` 编号、`{n:3}` 补零三位，起始编号默认 1，默认模式 `{n} {name}`）、**正则**（Go 正则 + `$1` 捕获组）、**查找替换**（字面替换）；三种模式都支持 `{created_year}`…`{modified_second}` 日期占位符。预览逐行实时更新，并且可交互：**拖动行**调整顺序（编号随之改变，`{n}` 因此按拖后的次序编号）、**双击（或 `F2`）逐项改写**目标名（改过的行「钉住」不再受模式影响，行尾 `↺` 恢复）、`↑/↓` 移动焦点。目标名为空、`.`、`..`、含路径分隔符、两项撞名（不区分大小写）或与文件夹里已有项目撞名时该行标红并说明原因，主按钮按可应用行数显示「重命名 N 项」；提交时整批走两段式改名（互换名字也不会丢文件），跳过冲突行，失败项在状态栏点名，整批压入**一次**撤销（`Ctrl+Z` 一次全还原）。

**压缩 / 解压**
任意选择「压缩为 ZIP 文件」（单选以原名命名，多选为“压缩文件”）。解压支持 zip、tar、tar.gz/tgz、tar.bz2/tbz2（标准库纯 Go），tar.xz（系统 `bsdtar`），7z/rar（需安装 `7zz` 或 `unar`）。解压到以归档名命名的子文件夹；成员路径含 `..`、绝对路径或反斜杠（zip-slip）一律拒绝，符号链接成员跳过。

**回收站**
“此电脑”下的回收站页列出 `~/.Trash`。本应用删除的项目可**还原**到原位（删除时记录来源路径，原文件夹缺失会重建、重名自动避让）；**永久删除**与**清空回收站**弹出系统确认对话框（`mygo.Dialog`）。

**撤销**
`Ctrl+Z` 依次撤销最近的 复制/移动、重命名、删除（从废纸篓放回）、新建文件夹/文本文档、压缩、解压、还原；栈深 64，**只活在进程内**（每个窗口一份，关闭窗口或退出应用即清空，不写进 `state.json`）。撤销时若原位置已被占用或待撤文件已不存在，该项跳过并在状态栏点名，不会覆盖任何东西。

**搜索**
搜索框（`Ctrl+E` / `Ctrl+F` / `F3` 聚焦）输入即在后台递归搜索**当前文件夹**及其全部子文件夹，命中**流式**进列表——边找边显示，不必等整棵树走完；结果按当前排序键排列（文件夹在前，点列头即换键/换向），状态栏是 Everything 式的一行：「本文件夹 “alpha”  找到 42 个项目 (1.2s)」。上限 5000 条、8 秒超时，默认跳过隐藏目录；详细信息视图在搜索时自动切换出「位置」列。

`Ctrl+K`（`Cmd+K`）唤起**全局搜索面板**：独立的无边框磨砂玻璃窗口（Raycast / Spotlight 那种面板，浮在所有应用之上、不进任务栏和程序坞，系统有毛玻璃材质时透出背后的内容），自带查询框与「本文件夹 / 全部磁盘」切换（默认**全部磁盘**），结果**按名称排序**实时列出名称、位置、大小、修改日期（新命中排进正确的位置，光标始终停在你选中的那一项上）；`↑`/`↓` 选择（`PageUp`/`PageDown` 按页），`Enter` 打开（文件夹即进入，文件先跳到所在文件夹再打开），`Ctrl`/`Cmd+Enter` 在文件夹中显示（跳到所在文件夹并选中），行内右侧的「位置」按钮用鼠标做同一件事，`Esc`、再次按 `Ctrl+K` 或点到别处即收起；收起即取消仍在跑的搜索。快捷键在别的应用里也有效，可在设置 → 托盘 → 快速搜索里改（点击后按下新组合，Backspace 恢复默认）。底行写明这一份列表是谁答的：`索引命中 · 找到 42 个项目 (39µs)`、`索引 + 实时遍历（未完整） · 正在搜索…  已找到 42 个项目 (1.2s)`，或没索引时的 `实时遍历 · 找到 42 个项目 (2.4s)`。到 5000 条上限时状态行会写明「已达 5000 条上限」——结果不再完整，不装作完整。

**搜索索引**（`searchindex.go`，Everything 的那个索引）：启动时先读上次遍历写下的 `sunvale/index.json`——覆盖到所搜范围就**当帧命中**，不必等磁盘——同时在后台把全部卷再走一遍（**先走主文件夹**，再走各卷并跳过已走过的部分，2 条并行、20 万条上限、10 分钟上限），走完整份替换并写回缓存；关窗时若还在建，把已走到的部分存下并标记「未完整」，下次启动照样先热起来。索引里只有路径与大小/日期，匹配用的是与遍历**完全同一套**查询语言（`internal/searchquery`），隐藏项照常按「显示隐藏的项目」过滤；面板自己的列表（导航、`F5`、新建/重命名/删除后重读的那一份）**即时回填**进索引，所以刚在资源管理器里看到的文件立刻能搜到。索引答不了的地方不装作答得了：快照不是整台机器（撞了 20 万条上限、或上次没走完）时，索引**先给立刻命中**，同一批后台遍历紧接着在它上面补齐（两边都找到的文件只列一次）；覆盖不到的范围（还没走到的目录）直接回落到实时遍历。底行空查询时写的是索引自己的状态（条数、缓存多旧、是否正在重建），右边是「重建索引」按钮，重建期间显示「正在重建 N 条」。

查询语法对齐 Everything（`internal/searchquery`）：空格分隔的多个词是 **AND**；`"完整短语"`；`case:` 自该处起区分大小写（再写一次切回）；`file:` / `folder:` 只看文件/文件夹（`folder:rep` 即名字含 rep 的文件夹）；`ext:txt;md` 按扩展名；`path:docs` 按完整路径。引擎不支持的修饰符（`regex:`、`dupe:` 等）**照原样当普通搜索词**，不静默变成别的含义。命中的片段在名称里以**黄色底色**标出（Everything 的标记），详细信息、列表、图标视图与 `Ctrl+K` 列表一致。

**主页（主文件夹）**
导航树顶部「主文件夹」是资源管理器的 Home 页：**快速访问**磁贴（单击文件夹即进入，单击文件则打开它所在的文件夹并选中它；首次运行按 Windows 11 默认固定 桌面/下载/文档/图片/音乐/视频 中存在的项）+ **最近使用的文件**（本应用打开过的文件，最新在前，最多 20 条）。文件或文件夹右键「固定到快速访问」，也可以直接拖到侧边栏或主页的「快速访问」上固定。侧边栏或主页磁贴右键「从快速访问取消固定」。

另有「项目复选框」开关（`查看 > 显示` 或设置里的「查看」页）：打开后详细信息、列表与小图标视图在文件图标前多一个 16×16 方框，勾选状态即该项是否被选中，点方框只切换这一项、不移动选择锚点。复选框只在 `nameCell` 里绘制，而它只服务详情行、列表行与小图标磁贴，所以中等 / 大 / 超大图标视图与画廊磁贴不会出现复选框。

**画廊**
侧边栏「主文件夹」之下的图片画廊页（插件「画廊」）：扫描 `~/Pictures` 及其子目录，按修改时间**从新到旧**、以「2026年10月（12 张）」这样的月份分组铺成缩略图网格，最新月份在最上。收集 `png jpg jpeg gif webp bmp heic tif tiff avif ico`，跳过任意层级的隐藏项与 `*.photoslibrary` 包，上限 **2000 张**；进入页面即重扫一次，`F5` 也重扫。

缩略图最长边 **200 像素**：标准库能解的格式（含 WebP/BMP/ICO）用 Catmull-Rom 缩放，HEIC/TIFF/AVIF 走系统 Quick Look（非 macOS 上这些格式解码不到缩略图，文件仍在列表里）；解码 4 路并发、内存缓存 400 张按 LRU 淘汰，每解码 8 张重绘一次。页面的交互与文件区一致：单击选中、双击交系统默认程序打开、`空格` 快速预览、可框选、拖出窗口即系统拖拽源、右键用同一套条目菜单（打开、剪切、复制、删除、属性可用；打开方式、粘贴、复制为路径、重命名、压缩/解压、在终端中打开、刷新统计因是特殊页而置灰）；方向键在该页始终按网格移动（不论「查看」停在哪一档），`PageUp`/`PageDown` 按可见行数。该页只读：不是放置目标，也不接受新建/粘贴/重命名。

**打开方式**
文件右键「打开方式」列出在 `Info.plist` 中声明支持该扩展名的应用（首次打开菜单时后台扫描 `/Applications` 与 `/System/Applications`，经 `plutil` 解析，八路并发），点选即用 `open -a` 打开；末尾提供「在 /Applications 中查看…」。

**扩展命令（Shell 扩展协议）**
对应资源管理器的注册表动词：在配置文件中登记的命令会出现在匹配文件的右键菜单里，按注册顺序排列，带占位符与可选终端执行（详见下方「配置文件」）。

**分享**
命令栏「分享」（需先选中文件）打开分享对话框：可设访问密码与有效期（永久/1 小时/1 天/7 天/30 天），创建后给出 `/sd/<id>` 链接，一键复制。分享由应用自带的远程服务创建（走 `/api/share/create`，与浏览器管理端同一套存储与校验），因此需要先在 查看更多 中开启远程访问；只支持主文件夹内的项目，主文件夹之外的路径会被明确拒绝而不是被悄悄改成别的路径。

**拖拽移动**
把文件拖到文件夹行、侧边栏位置、面包屑层级、标签页或主页文件夹磁贴即移动过去；拖到侧边栏或主页的「快速访问」标题（主页标题下磁贴之间的空白也算）则固定，不移动也不复制；拖到右侧助手的对话记录或输入框则指定给这一轮，不移动也不复制；按住 `Cmd/Ctrl` 拖为复制；行在选中集合内时携带整个选择；同名自动「名称 - 副本」避让，跨盘（EXDEV）移动回退为复制后删除，把文件夹拖进自身或子目录会跳过；可把文件夹拖到标签页移到该标签文件夹。行同样是**系统拖拽源**：把文件拖出窗口，Finder / 资源管理器收到的是文件列表，由放置目标执行移动或复制。从其他应用拖入的文件是**复制**到目标文件夹（空白处即当前文件夹），不论是否按住修饰键——原件属于源应用，不在这里移动；非本地文件的链接（`https://` 等）会被忽略并在状态栏说明。拖过时目标高亮。

**空格快速预览（Quick Look）**
选中单个文件按 `空格` 打开模态快速预览（图片/文本/音频播放器/视频与 PDF 海报），底部一行文件摘要；`空格` 或 `Esc` 关闭，点击外部也关闭。它复用预览窗格已加载的解码结果，同一文件只解码一次。

**预览窗格**
选中单个文件时在右侧显示预览与属性，随选择实时切换：

- **图片**：PNG/JPEG/GIF/WebP/BMP 走 MyGo 的 `ui.DecodeBitmap`（含 JPEG EXIF 方向修正）；HEIC/AVIF/TIFF/SVG 走系统 Quick Look（`qlmanage -t`）出 PNG 后解码。
- **视频**：`ffmpeg` 抽帧生成海报 + `ffprobe` 读时长/分辨率/编码，Quick Look 兜底；面板给「打开」按钮交给系统播放器（与 Explorer 一致：静态帧 + 元数据，不内嵌播放）。
- **音频**：WAV/MP3/Ogg Vorbis 用 MyGo 的 `audio` 包（纯 Go、无 cgo）**内置播放**——播放/暂停按钮、点击进度条跳转、`空格` 播放/暂停、`←/→` 快退快进 5 秒；不支持的格式回退「打开」。
- **文本/代码**：只读文本框显示前 64 KB，附「约 N · 已显示前 M」提示。
- **PDF / Office 文档**：Quick Look 渲染首页 + 「打开」按钮。
- **任意文件**：文件名、类型、大小、修改/创建日期、位置；图片/视频/音频再附加尺寸、页数、时长、分辨率、编码等元数据（`mdls` / `ffprobe`）。

加载全部在后台 goroutine 完成，结果以代际号（gen）原子替换，慢加载不会覆盖更新的选择。

**属性对话框**
`Alt+Enter`、行右键「属性」或侧边栏文件夹右键打开模态属性对话框（仅单选，文件与文件夹都支持）。抬头是 40 像素图标与名称，图片额外显示一张缩略图（最高 220）；字段表为名称、类型、大小（文件夹显示「N 个项目」）、修改日期、创建日期、位置，再按类型追加元数据——视频/音频走 `ffprobe`（时长、分辨率、视频/音频编码），图片与文档在 macOS 走 `mdls`（尺寸、页数），并附上已启用插件声明的元数据行。底部三个按钮：在 Finder 中显示（`open -R`）、打开、确定。文件夹的事实由专属后台加载（预览管线只服务文件），落地前显示「正在读取属性…」。

**此电脑**
以 `/`（命名为 Macintosh HD）加各 `/Volumes` 挂载点列出卷（含外接磁盘），按设备号去重；每个卷显示**容量使用条**（蓝色为已用比例）与「可用 X，共 Y」，详细信息视图有专门的宽列，图标视图在名称下方画条，悬停出百分比提示（`statfs`）。

**磁盘健康**
「此电脑」展开后的「磁盘健康」页（插件「磁盘健康」）是一页可视化诊断，从上到下四层：

1. **概览条** —— 四块磁贴：磁盘数、健康分布（N 正常 / N 注意 / N 异常）、最高温度（按 50/60 °C 变色）、总容量与可用。
2. **每块盘一张卡片**。左栏是身份与结论：型号、设备名、**健康评分环**（0–100，环的颜色随分档变化）、评分文字与徽章，以及接口/介质/序列号/固件。右栏是两条：三条**指标条**（容量、温度、写入寿命，各自映射物理量程——温度按 20–80 °C 铺满，超过阈值即变色并加注说明）和一张**实时读写曲线**（读/写两条线，按探测间隔采样；底部一行显示最新或选中采样点的数值）。
3. **检测项** —— 一排状态胶囊：SMART 状态、温度、备用块、写入寿命、介质错误、通电时长、容量使用。每项带「正常/注意/异常/未知」与一个圆点色标；非「正常」的项把原因放在悬停提示里。
4. **统计与卷构成** —— 一张累计统计磁贴行（总容量、通电时长、通电次数、异常断电、介质错误、累计读写、读写次数、备用块），以及**卷构成环形图**（Onevra `chart.Donut`）：按卷分组的已用空间，APFS 的十来个系统卷折成「系统（N 个卷）」，下方图例（Onevra `components.List`）列出挂载点、体积与占比。

卡片左上角的图标会识别盘厂：按型号字符串匹配（`APPLE SSD`、`ST…`、`WDC…`、`MZ-…` 等），命中就在状态色方块上画出该品牌的白色 logo，副标题写成「Apple · disk0」；认不出的品牌回退到通用硬盘图标。logo 来自 [Simple Icons](https://simpleicons.org)（CC0 1.0，见 `brandicons/LICENSE.simple-icons`），以 `go:embed` 内嵌进二进制，离线可用、不发网络请求。目前收录 Apple、Seagate、Western Digital、SanDisk、Toshiba、Samsung、Kingston、Hitachi/HGST、Intel、Lenovo、Dell、HP、Synology、QNAP 十四家。

页面尽量用 Onevra 组件而非手搭：曲线与环形图是 `chart.Line` / `chart.Donut`，指标条是 `components.Progress`（Onevra 固定用主题强调色绘制，这里覆写绘制函数换成该项的状态色——轨道、圆角、几何都不变，只有颜色承载结论），检测项是 `components.Badge` 加 `components.Tooltip`，卷图例是 `components.List`，图标来自 `lucide`，刷新按钮是 `components.IconButton`。状态色（正常/注意/危险）取自 `c.Theme()` 的 `Success` / `Warning` / `Danger`（`appTheme` 已把应用的 Windows 11 token 装进主题），因此跟随浅深色与高对比度设置，不再硬编码十六进制。评分环是唯一手绘的图形：`components.ProgressRing` 同样固定强调色，而评分环的颜色本身要表达分档。

页头写明读取时间、数据来源与采样窗口，右上角的刷新按钮与 `F5` 一样强制重探。

**健康评分**由检测项推出，二者不会互相矛盾：从 100 分起扣——「注意」扣 6（容量、通电时长、写入寿命这类慢变量）或 12（温度、介质错误），「异常」扣 45；SMART 判定为失败时分数封顶 40，因为其它项看起来正常也不能掩盖它。**没有任何可测指标时不给分**，显示「无可测指标」而不是假装 100 分。分档写法：≥90 健康、≥70 良好、≥50 注意、其余危险。

数据来自 `diskhealth` 包（`diskhealth/`），UI 只负责画：

| 平台 | 来源 | 能拿到什么 |
| --- | --- | --- |
| macOS | `diskutil list/info/apfs list` 的 plist（经 `plutil` 转 JSON）、`system_profiler` 的 NVMe/SATA 段、可选 `smartctl` | 型号、序列号、固件、总线、介质、SMART 状态、温度、寿命已用%、备用块与阈值、通电时长/次数、异常断电、介质错误、累计读写字节与命令数、每个 APFS 卷的角色 |
| Linux | `/sys/block`（跳过 loop/ram/dm-/zram/sr/md/nbd）、挂载表、可选 `smartctl` | 型号、序列号、固件、介质、SMART 通过/失败、NVMe 温度（hwmon）；寿命、计数与写入量需 `smartctl` |
| Windows | PowerShell `Get-PhysicalDisk` + `Get-StorageReliabilityCounter` + `Get-Disk` + `Get-Partition` | 型号、序列号、固件、总线、介质、健康、温度、通电时长、磨损百分比、盘符与容量 |
| 其他 | 无 | 页面写明此平台暂不支持 |

macOS 是这次重构的重点：Apple Silicon 的 `SPNVMeDataType` 只给型号与 SMART 状态，而 `diskutil info -plist` 的 `SMARTDeviceSpecificKeysMayVaryNotGuaranteed` 带着整套 NVMe SMART 键（`DATA_UNITS_READ/WRITTEN`、`PERCENTAGE_USED`、`AVAILABLE_SPARE`、`POWER_ON_HOURS`、`TEMPERATURE`…）。两个字段的单位按 NVMe 规范处理并已实测标定：`DATA_UNITS_*` 每单位 1000×512 字节（读一个 369 MB 文件恰好增加 724 个单位），`TEMPERATURE` 是开尔文（322 → 49 °C，加热 4 GB 后升到 56 °C）。低于 200 K 的读数当作传感器异常，显示「未知」而不是负温度。

容量的口径是**容器的池**而不是卷的加总：一块盘上所有 APFS 容器各计一次 `CapacityCeiling` / `CapacityFree`，否则同一批共享空间会被卷重复计入。

实时曲线与「读 X/s · 写 Y/s」都是**两次探测之间的差分**（每 3 秒探一次，只在页面可见时轮询）：第一次探测没有可比较的基线，显示「采样中…」；没有读写活动时显示「空闲」；平台不提供累计计数器时显示「未知」。进入页面即开始轮询，离开页面、关闭窗口或停用插件都会停掉，不在后台空转。历史上限 200 个采样点（约十分钟）。

插件页可设**高温警告**开关与 **40/50/60/70 °C** 阈值（默认开、50 °C）；关掉警告后温度一项不再判为「注意」。插件页另有「复制磁盘报告」，把每块盘的全部字段（含评分与逐条检测结果）写成纯文本进剪贴板。

**设置**
命令栏 `查看更多（…）> 设置` 或 `Ctrl/Cmd+,` 打开设置对话框（Onevra 的设置壳：左侧分类、顶部可搜索、右上角关闭）。分页为**外观**（跟随系统 / 浅色 / 深色）、**查看**（文件扩展名、隐藏的项目、项目复选框、紧凑视图、预览窗格、默认视图、启动时恢复会话）、**托盘**（磁盘容量、读写速度、快速搜索快捷键）、**扩展**（登记的右键命令，见下）、**插件**（内置插件的启用开关与其自有设置，见下方「插件」）、**更新**（当前版本、自动检查更新、自动下载并安装、检查更新、上次检查）。设置持久化在 `sunvale/state.json` 的 `settings` 字段，更改即时应用到所有打开的窗口。**恢复默认**只还原外观与查看，不动插件和更新选项。**外观**的选择同样持久化（`appearance`，缺省即跟随系统）：选定即重算配色并重绘所有窗口——`theme.go` 的 token 与 MyGo 自带控件不会各切一半；系统在运行中切换外观（macOS 的自动浅色深色）时也走同一条重绘路径。

**托盘**
最小化或关闭窗口都收到系统托盘，进程在后台继续运行（不占任务栏），首次如此弹一次系统通知。托盘左键单击或菜单「显示晴谷」恢复窗口（窗口已全部关闭则新开主窗口）。只有菜单「退出晴谷」会退出；托盘没能建起来时，关闭仍是真正关闭，避免窗口消失后无法返回。托盘菜单：

- **快速搜索…** —— 打开 `Ctrl+K` 的全局搜索面板（全部磁盘范围，索引即时应答，见「搜索」）：不把文件窗口带到前台；没有窗口时先建一个藏在托盘里的。
- **显示晴谷 / 新建窗口** —— 恢复现有窗口，或按 `Ctrl+N` 的样子新开一个。
- **磁盘信息** —— 每块磁盘的「可用 X / 共 Y（占用%）」与整机实时「读 X/s · 写 Y/s」，数据来自磁盘健康插件的后台采样，探测落地（约每 3 秒）即自动刷新菜单；「刷新磁盘信息」立即强制重采。两项各有一个菜单里的勾选开关「显示磁盘容量」「显示读写速度」，与设置对话框 `托盘` 页的开关是同一份设置，双向同步；都关掉时菜单不再采样、不显示磁盘行。
- **退出晴谷**。

**助手**

命令栏和「查看」菜单里的「助手」打开右侧窗格（Onevra 的对话记录和输入框）。左缘可以拖宽，顶栏的全屏按钮让它占满侧栏右侧的整块区域（侧栏还在，方便换文件夹）；再点一次还原。拖宽、全屏和「全托管」会记住。模型是用户添加的 OpenAI 兼容接口，密钥写在本机 `sunvale/assistant.json`（权限 0600）。输入框左侧可以选择模型：打开列表时读取当前供应商的 `/models`，选中的模型写回该供应商。

文件能力是进程内的 MCP 服务，Eino 只通过这些工具操作：列出、读取、按文件名搜索、在文本里查找、文件夹摘要、磁盘剩余空间、属性、新建文件夹和文本、写入文本、复制、移动、移到回收站、单个重命名、压缩、解压、用系统打开、打开终端、复制路径、让窗口跳转到某个文件夹，以及解压密码库。复制、移动和删除的来源限制在当前标签页的文件夹，目标可以是用户给出的绝对路径。`list_outside` / `read_outside` 用绝对路径查看文件夹以外的位置。`read_files` 一次读用户指定的多个路径（相对当前文件夹或绝对路径），大文件只给开头。对话记录和输入框都可以拖入文件，只挂上路径，不移动也不复制；也可以点回形针多选，或把列表里的选中项带上；粘贴一行已存在的路径也会挂上。批量 `rename_plan` 只出方案，点「应用方案」才改名；单个 `rename_item` 会立刻改名。删除是移到系统回收站，可撤销，没有永久删除。`write_text` 新建的文件可以撤销，覆盖已有文件不会恢复原文，并且不会改密钥、cookie 或私钥。密码本保存的是压缩包解压密码：模型只能看到名称，`unzip` 会在本机按顺序尝试，密码正文不会进入提示词或回复。

回复按流式逐段出现，思考过程显示在状态行里。供应商返回限流（429）且这一轮还没写出文字时，助手会改用同一模型的其他线路并记住它；已经写出的内容不会重跑。都不可用时，回复里说明恢复时间，而不是抛出原始错误。工具一旦被点名就出现在这一轮里，调用中的那条会标成进行中；整轮完成后收成一行「调用了……」。输入框在回答时变成「停止」，已经写出来的文字会留下。输入框左侧的「全托管」打开后，助手自己把说清楚的事做完，不再每一步征求同意；批量重命名方案会在这一轮结束时自动应用。没打开时，改动很多文件或覆盖已有文件之前会先问。需要用户拍板时，助手给出可勾选的做法（默认能多选），点「发送所选」才继续。比较、清单或下一步操作时，回复里可以带一块 OpenUI（卡片、表格和按钮）。按钮把一句中文当作下一条消息发出，不会直接改文件。远程接口返回的 text 里仍是这块原文。系统提示词在 `assistant_prompt.go`，界面语法在 `assistant_openui.go`。

会话会留下来。顶栏「会话」可以新开、切换和删除；关掉窗口或退出后再打开，还是上次那段。记录在用户配置目录的 `sunvale/assistant/sessions/`，列表是同目录的 `index.json`（不是搜索用的 `sunvale/index.json`）。每段只留最近的对话。指定文件时自动附上的正文不写入磁盘，重新打开后要再读。

记忆是跨会话的短事实，和某一段对话分开，存在 `sunvale/assistant/memory.json`。说「记住……」或在「会话」面板里写一句就会记下，说「忘掉……」或点删除就去掉。密码和密钥不要放这里。

远程访问开启后，助手同时提供 HTTP A2A 与 Streamable HTTP MCP。两者都要求远程访问的管理员令牌，支持 `Authorization: <token>` 或 `Authorization: Bearer <token>`：

- `GET /.well-known/agent-card.json`（别名 `/.well-known/agent.json`）是公开的 Agent Card，声明不支持流式、支持任务状态历史。
- `POST /a2a`（别名 `/a2a/v1`）使用 JSON-RPC 2.0，支持 `message/send`、`tasks/get`、`tasks/cancel`。`message/send` 的 `metadata.folder` 是远程存储的虚拟路径，默认 `/`；`metadata.files` 或 `file://` part 指定要读的文件。任务在后台执行，结果通过 `tasks/get` 获取。
- `POST /mcp` 是 OAuth 无关的管理员 MCP，工具包括 `assistant_config_list`、`assistant_config_save`、`assistant_config_activate`、`assistant_config_delete`、`assistant_status`、`a2a_info` 和 `assistant_run`。配置列表只返回 `keyConfigured`，不返回 API Key；保存时留空 `apiKey` 会保留原密钥。

`assistant_run` 与 A2A 都走与窗口相同的进程内文件 MCP。调用方可以用 `folder` 选择远程挂载点，用 `files` 点名文件；A2A 的绝对文件路径按助手的既有规则处理。API Key、解压密码正文、远程令牌和私钥内容不会出现在协议响应中。任务表只保存在内存里，重启后清空。

真实供应商验收可显式开启（默认单测不会联网）：设置 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`SUNVALE_LIVE_MODEL` 后，运行 `SUNVALE_LIVE_A2A=1 go test -run TestA2ALiveProviderReadsNamedFile .` 或 `SUNVALE_LIVE_MCP=1 go test -run TestMCPLiveProviderReadsNamedFile .`；测试会在临时远程根目录写文件，分别经 A2A 和 MCP 让模型读取，并检查回复中不含 API Key。

## 自动更新

应用内置 [MyGo](https://github.com/egoist/mygo) 的 `mygo.Updater` 与 updater 插件，从**签名发布**自更新：`mygo build` 用 `mygo keygen` 私钥签名每个平台的更新包，应用用编译期内置于可执行文件的公钥校验签名后替换自己。设置对话框更新区的选项（自动检查更新、自动下载并安装等）持久化在 `sunvale/state.json`。

**发布端配置**（本仓库已配好）：

- `mygo keygen` 生成密钥对到用户配置目录 `mygo/update-keys/`：`mygo-update.key`（私钥，不入库、只进 GitHub secret）与 `mygo-update.pub`（公钥）。
- `mygo.json` 的 `updates` 字段登记 `publicKey`（公钥内容）与 `github`（`mcxen/WinExplorer`）。
- GitHub 仓库 secret `UPDATE_PRIVATE_KEY` 存 `mygo-update.key` 的内容，`release.yml` 构建时经 `MYGO_UPDATER_PRIVATE_KEY` 传入：每个平台随安装包上传 `update-<platform>.json` 清单（版本、发行说明、日期与归档/增量的 URL、大小、签名）、签名的 `sunvale-<版本>-<平台>.tar.gz` 更新包与 `.delta` 增量包；未设 secret 时构建照常、只跳过这些文件（Linux 的 `.tar.gz` 仍会生成，供 `install.sh` 安装）。
- 发布（publish job 的 `--latest`）后，应用读 `https://github.com/mcxen/WinExplorer/releases/latest/download/update-<platform>.json` 发现新版本并下载安装。

**增量更新**：签名构建读取各平台已发布清单，下载最近 3 个版本（`updates.deltas` 可调）的更新包，与新版本做 bsdiff 二进制差分出 `.delta`；应用只下载变化的部分，按清单的大小与 SHA-256 校验重组出与发布完全一致的新版本，失败或不比整包小时回退整包下载。

`go run .` 的开发构建与包管理器安装（deb 在 `/opt`）不能写安装位置，更新区显示「此构建不支持自动更新」；macOS 安装到 `/Applications`（或 `~/Applications`）、Windows 用户级安装（`%LOCALAPPDATA%\Programs`）与 Linux 的 `install.sh` 安装（`~/.local`）均可自更新，deb 安装交由系统包管理器更新。仓库暂无 `CHANGELOG.md`，清单的发行说明为空（发布页的自动 notes 不受影响）。

## 插件

内置插件在各自的功能文件里用 `registerXxxPlugin()` 登记（`plugins.go` 的注册表，顺序固定为远程访问 → 画廊 → GIF 自动播放 → 清理 .DS_Store → 重复文件查找 → 可视化查看占用 → 磁盘健康），在设置对话框的**插件**页管理——每个插件一张卡片：启用开关在上，它自己声明的设置行在下（停用时设置行随开关一起收起）。开关即时生效；停用状态记录在 `sunvale/state.json` 的 `plugins` 字段（只记停用的 id，字段缺省 = 全部启用，即首次运行的默认行为）。

**插件协议**：每个插件在注册表登记 `Plugin`（`RegisterPlugin`，id 重复即 panic），用可选钩子声明自己出现在哪里——`MenuItems`（右键菜单，文件区行/空白处与侧边栏位置共用同一收集器）、`MoreItems`（命令栏 查看更多）、`NavItems`（侧边栏位置）、`MetaRows`（预览窗格与属性的元数据行）、`Settings`（设置对话框插件页自己的设置行，声明式数据 `PluginSetting`——开关/下拉/信息行/按钮四种行，对话框统一渲染，插件不画 UI）、`OnEnable`/`OnDisable`（开关即时生效的善后）；每个插件还有自己的键值设置（`pluginGet`/`pluginSet`，存 `state.json` 的 `pluginSettings`）。后台异步工作走公共管线（`plugintask.go`）：`taskRunner` 负责串行化（一次一个任务、新请求顶掉排队请求）、进度期定时重绘与 goroutine 生命周期，`appFlag`/`appVal` 给对话框提供按窗口的状态——插件只写自己的扫描函数。

| 插件 | 功能 |
| --- | --- |

## 远程访问（OpenList 兼容）

把主文件夹（虚拟根 `/` 即本机 home 目录）通过局域网 HTTP 暴露给手机或其他设备，协议兼容 [OpenList](https://github.com/OpenListTeam/OpenList)（AList v3 API）的读、写与分享接口集。

**开启与账号**

- 命令栏 `查看更多（…）> 远程访问` 开关服务（插件「远程访问」停用时这两项从菜单隐藏，在设置的插件区重新启用）；开启后状态栏显示局域网地址（默认端口 5244，被占用时自动顺延 5245–5254）。
- `查看更多 > 复制远程地址` 一次复制 地址 / 账号 / 密码。账号与密码默认都是 `admin`（OpenList 惯例），首次登录后请在 `/@manage` 的「设置」页改掉；改过的密码持久化在 `sunvale/state.json` 的 `remote` 字段，重启后仍然有效。
- 账号与端口持久化在 `sunvale/state.json` 的 `remote` 字段；应用退出时自动停服务，已签发的登录令牌全部失效。

**`/@manage` 管理界面**：浏览器打开 `http://局域网IP:5244/@manage` 即是内置管理控制台（单文件内嵌，无外部资源）——仪表盘（运行状态与开关、存储容量、分享概览、OpenList 客户端接入信息）、文件（预览窗格 + 全屏浮层预览、全局搜索、右键 shell 命令）、分享（创建、复制链接、启停、删除）、存储（根目录与挂载点）、设置（改用户名/密码、重置 API Token、改端口、远程访问开关）。

**存储与远程首页**：`/api/storage/*` 与 `/api/driver/*` 对齐 OpenList 的 `model.Storage` 字段与端点。每条存储是一个挂载点：`mount_path` 是虚拟路径，`addition` 里的 `root` 是本机文件夹。挂载在 `/` 的那条就是**远程首页显示什么**——把它指到图片目录，首页列出的就是那个目录。首页顶部另有一排存储入口（`/api/fs/storage_list`），每个启用中的挂载点一个，点击进入该挂载；停用的不出现。备注会替换路径作为显示名。驱动目前只有 `local`（本机路径），其余驱动名会被拒绝而不是假装支持。停用一个挂载点会让它下面的路径整体不可达，不会静默回落到上层挂载；根挂载不能删除，只能停用。

**隐藏的项目**：远程首页顶栏的「隐藏」与管理界面设置页的「隐藏的项目」是同一个开关（`/api/fs/hidden`，记在 `state.json`）。关掉时文件列表和地址栏补全都不出现以点开头的文件与文件夹；打开后两边都列出。它与桌面端「查看 > 隐藏的项目」分开存，互不影响。

**文件页与桌面端同构**：命令栏 `新建▾ | 剪切 复制 粘贴 重命名 分享 删除 | 排序▾ 查看▾ | …`（没有选中时剪切/重命名/删除保持置灰，剪贴板为空时粘贴置灰，与客户端同一套开关规则）、地址行（后退/前进/向上/刷新 + 面包屑 + 搜索框）、左侧「位置 / 存储」导航树（主文件夹，桌面/文档/下载/图片/音乐/视频（存在才列出），以及本机存储与容量）、状态栏（项目数与选中体积，右侧当前视图）。六种视图（超大图标/大图标/中等图标/小图标/列表/详细信息）与名称·修改日期·类型·大小时升序/降序都可切换，选择记在 `localStorage`；详细信息视图可按列头排序，图标视图里图片直接以 `/d` 直链当缩略图。选择与键盘对齐客户端：单击、`Cmd/Ctrl+单击`、`Shift+单击` 范围选、`Ctrl+A` 全选，方向键移动（图标/列表视图按行列）、`Shift+方向键` 扩展、`Home`/`End` 到首尾、`Enter` 打开、`Backspace` 向上、`F2` 重命名、`F5` 刷新、`Delete` 删除、`空格` 快速预览、`Alt+P` 预览窗格。行右键菜单对齐 Windows 11：打开/预览、下载、剪切、复制、粘贴、复制为路径、重命名、压缩为 ZIP 文件、全部解压、解压到…、在终端中打开、（登记的扩展命令）、分享、删除、属性；空白处菜单提供新建文件夹/文本文档、上传、粘贴、排序方式、查看、显示隐藏的项目、显示项目复选框、刷新。向上、后退回到上一层时选中刚离开的那一项并滚到它；地址栏输入文件路径、搜索结果跳转也是选中后滚到该行。删除、复制、粘贴、重命名只刷新当前列表并保持滚动位置，不弹回最上面。

**批量重命名（远程）**：多选时命令栏「重命名」、右键「重命名」或 `F2` 打开同一个对话框的网页版——模板/正则/查找替换三种模式、逐行实时预览、**拖动行改变编号**、**双击逐项改写**（行尾 `↺` 交还模式）、冲突行标红且不应用，提交走 `/api/fs/batch_rename`（与桌面端共用的 `internal/rename` 引擎）。

**手机端适配**：宽度 ≤720px 时侧栏折成底部四个标签（仪表盘/文件/分享/设置，退出登录移到顶栏），卡片单列，命令栏单行横向滑动（上传与 `…` 靠前，排序/查看可滑出），地址行折成「向上/刷新/编辑/搜索范围 + 面包屑 + 搜索框」三行，详细信息视图只保留名称与修改日期（更窄时连日期一起收起）、行高与按钮放大到指尖尺寸，分享页一条分享一张卡片（链接独占一行、操作按钮铺满），菜单与弹窗变成底部动作面板/抽屉，并适配刘海屏安全区。触屏（粗指针）上补上鼠标没有的手势：**轻点即打开**、**长按弹出与右键同一套菜单**（含空白处长按的新建/上传/排序/查看）、浮层预览**左右滑动切上一张/下一张**、图片**双指缩放**（0.2×–5×，双击复原）。桌面端交互不变。

**预览（远程，参考 OpenList）**：预览窗格与全屏浮层共用一套渲染（图片 `<img>`、视频 `<video controls>` 自动播放、音频 `<audio controls>`、PDF `<iframe>`、文本 `<pre>` 前 64 KB，走 `/api/fs/get` 的 `raw_url`+`sign` 直链）。全屏浮层提供 **上一张 / 下一张**（在当前文件夹的图片与视频间循环步进，`←`/`→` 与手机左右滑动同步）与**图片缩放**（滚轮或双指 0.2×–5× 居中缩放，双击复位）；预览窗格保持适合显示。

**全局搜索（远程）**：地址栏搜索框旁的「本文件夹 / 全局」切换：全局模式下输入即递归搜索整个虚拟根（本机 home 目录），走 `/api/fs/search` 的 `global:true`（8 秒上限，与桌面端同一超时），结果带**位置**列（`/` 显示为主文件夹），点击结果跳到所在文件夹（文件并直接打开预览）；`Esc`、刷新、清空或导航即回到当前文件夹列表。

**右键 shell（远程）**：管理端文件页右键菜单提供「在终端中打开」（文件夹；在本机打开系统终端并定位到该目录）与本机 `winexplorer/extensions.json` 登记的**扩展命令**（按匹配过滤、注册顺序排列，服务端分离执行，慢命令不阻塞页面）：`/api/fs/ext/list`（列出匹配项）、`/api/fs/ext/run`（执行）、`/api/fs/terminal`（开终端），均管理鉴权、拒绝 `..` 逃逸；扩展命令与桌面端右键共用同一注册表。

**拖拽**：行可拖拽，文件夹行、面包屑、导航树都是放置目标——直接拖就是移动，按住 `Cmd/Ctrl` 拖是复制（同桌面端）；从系统（Finder / 资源管理器）拖文件到页面即上传到当前文件夹、拖到某个文件夹行则上传进那个文件夹，带进度条与失败重试。

**压缩与解压（远程）**：`/api/fs/archive/unzip` 把每个归档解压到以归档名命名的子文件夹（重名按「- 副本」递增，与桌面端同名），`/api/fs/archive/zip` 把选中的项目打包成一个 ZIP（单选以原名命名、多选为「压缩文件」）；两者都接受 `names` 批量数组与可选 `dst_dir`，`/api/public/archive_extensions` 因此返回可解压的后缀表（`.zip` `.tar` `.tar.gz` `.tgz` `.tar.bz2` `.tbz2` `.tar.xz` `.txz` `.7z` `.rar`）。实现完全复用桌面端的 `extractArchive` / `makeZip`：zip-slip 拒绝、符号链接跳过、tar 家族纯 Go、tar.xz 走系统 `bsdtar`、7z/rar 走 `7zz`/`unar` 全一致；解压失败会删掉半成品文件夹，批量里个别失败在 `reason` 里说明、其余照常完成。同步完成，不排队。

**写操作与上传**：`/api/fs/mkdir`、`rename`、`move`、`copy`、`remove`、`dirs`（只列一层子文件夹）、`put`（`PUT` 上传：`File-Path` 头携带 URL 转义的目标路径，`Overwrite: false` 时冲突拒绝，`Last-Modified` 毫秒时间戳随行，落地走临时文件+原子改名）。删除与桌面端同语义：**移入 `~/.Trash` 并记录来源路径**，回收站页可还原；move/copy 整批预检——冲突既不跳过也不覆盖时整批拒绝且源不动，目录复制可 `merge` 合并，移入自身子树自动跳过。

**分享系统**：管理端 `/api/share/{create,list,get,update,delete,enable,disable}`（8 位随机 id、自定义 id 支持中文、密码/过期时间/访问次数上限/备注），访客链接形如 `http://IP:5244/@s/<id>`，**免登录**浏览（挂在 `fs/list`、`fs/get` 的 `@s` 分支）与下载（`/sd/<id>/<路径>?pwd=` 直链，支持 Range/HEAD）；同一 IP 半小时内多次访问只计一次，分享内的对象 `sign` 恒为空、`write` 恒为关；过期/停用/超次后访客得到协议的失效应答。分享持久化在 `sunvale/state.json`。主页面直接打开分享链接：带密码时弹框输入重试，单文件分享直接进预览。

**`/api/sunvale/*` 管理端点**：`status`（开关/端口/地址/容量/分享数）、`account`（改用户名/密码；改密后所有已签发登录立即失效）、`reset-token`（换发主令牌——它同时是登录签发与下载签名的密钥，旧令牌与旧签名直链全部失效）、`port`（范围校验、占用时整段顺延、失败回滚旧端口）、`enabled`（幂等开关）。供 `/@manage` 使用，OpenList 客户端不感知。

**内置网页端**：浏览器直接打开地址即可——登录、目录浏览（目录在前）、面包屑导航、当前目录递归搜索、图片/视频/音频/PDF/文本预览、下载、分享链接的访客模式（密码重试、免登录），右上角「管理」直达 `/@manage`。

**OpenList 客户端接入**：站点地址填 `http://局域网IP:5244`，账号 `admin` + 复制到的密码；列目录、取文件、写操作、上传、签名直链下载（含 Range 断点续传）均可用。

**协议范围**

- 已实现：`/api/public/settings`、`/api/public/archive_extensions`（可解压后缀表）、`/api/auth/login`（明文）与 `/api/auth/login/hash`（StaticHash）、`/api/me`、`/api/auth/logout`、`/api/fs/list`、`/api/fs/get`、`/api/fs/search`（`global:true` 全局）、`/api/fs/mkdir`、`/api/fs/rename`、`/api/fs/batch_rename`、`/api/fs/regex_rename`、`/api/fs/move`、`/api/fs/copy`、`/api/fs/remove`、`/api/fs/dirs`、`/api/fs/put`、`/api/fs/archive/unzip`、`/api/fs/archive/zip`、`/api/fs/ext/list`、`/api/fs/ext/run`、`/api/fs/terminal`、`/api/share/{create,list,get,update,delete,enable,disable}`、`/d/`（下载）、`/p/`（流式代理，支持 Range/HEAD）、`/sd/`（分享直链下载）、`/@s/<id>`（分享访客浏览）、`/@manage`（管理界面）、`/api/sunvale/{status,account,reset-token,port,enabled}`、`/`（内置网页）与 `/ping`。
- 未实现：`/api/admin/*` 与异步任务队列（写操作、上传与解压同步完成，即答即毕）——OpenList 客户端中的站点管理类按钮不可用属预期；`/api/fs/archive/list`（归档内预览）未实现，故 `settings` 里 `preview_archives_by_default` 保持 `false`。
- 所有 `/api/*` 响应恒为 HTTP 200，错误以 body `{"code":...}` 表达；`Authorization` 头携带裸令牌（无 `Bearer` 前缀）；下载签名 `sign = base64url(HMAC-SHA256(令牌, 路径 + ":0")) + ":0"`。
- 读接口（list/get/search/dirs 及写操作）同时接受 JSON body、表单 body 与查询参数，`path`/`parent` 缺省即虚拟根 `/`；对象 `type` 按 OpenList 默认的 audio/video/image/text 后缀表判定，文件夹 `size` 恒为 0；虚拟根在 `fs/get` 里名为 `root`，视频文件的 `related` 返回同目录同前缀的兄弟文件（字幕/弹幕）。

## 配置文件

四类用户数据，均在 `os.UserConfigDir()`（macOS：`~/Library/Application Support`）下：

**`sunvale/state.json`** —— 快速访问固定项、最近使用的文件、回收站还原日志、视图设置与**外观模式**（`settings.appearance`，`light`/`dark`，缺省即跟随系统）、插件停用表（`plugins`，只记停用的 id）与各插件的自有设置（`pluginSettings`，键值对）。由应用自动读写；旧版目录名 `winexplorer/` 会被自动迁移读取。只有经 `loadState` 读到的 store 会落盘，测试里在内存构造的 store 不碰这个文件。

**`sunvale/sizes.json`** —— 文件夹大小统计的磁盘缓存（上限 4096 条、最旧先淘汰，防抖 5 秒落盘、退出时落盘），由应用自动读写。

**`sunvale/index.json`** —— 搜索索引的磁盘缓存（版本号、上次遍历完成时间、是否走完整台机器、全部条目），由应用自动读写：启动时读入即用，后台重建后整份写回（先写 `.tmp` 再改名，绝不半写）；版本不符或文件损坏即当没有索引，重新走一遍。

**`winexplorer/extensions.json`** —— 扩展命令注册表（Shell 扩展协议）。文件不存在则无扩展；格式错误会在启动时忽略并在状态栏提示。

```json
[
  { "name": "用 VSCode 打开", "match": ["*"],   "command": "code \"{path}\"" },
  { "name": "转为 MP3",      "match": ["wav", "flac"], "command": "ffmpeg -i \"{path}\" \"{stem}.mp3\"", "terminal": true },
  { "name": "在此打开终端",  "match": ["dir"],  "command": "cd \"{path}\" && clear", "terminal": true }
]
```

- `match`：`*` 匹配全部，`file` 仅文件，`dir` 仅文件夹，否则按扩展名（不区分大小写，可写 `wav` 或 `.WAV`）。
- `command` 占位符：`{path}` 完整路径、`{dir}` 所在目录、`{name}` 文件名、`{stem}` 去扩展名、`{ext}` 扩展名。
- `terminal: true` 在新 Terminal 窗口执行（经 `osascript`），否则以 `sh -c` 分离执行，慢命令不阻塞界面。
- 路径沿用旧目录名 `winexplorer/`（不是 `sunvale/`），升级后原有扩展命令继续有效；桌面端与远程访问的右键共用这一份注册表。

## 实现说明

- **图标分层**：单色命令/导航图标（后退、前进、向上、刷新、剪切、复制、粘贴、重命名、分享、删除、新建、排序、查看、更多、搜索、播放/暂停等）统一使用 Onevra 内置 Lucide 图标，经 `components.Icon` 渲染、继承文本色；命令栏与导航行的图标按钮用 `components.IconButton`。**彩色**文件、文件夹、盘符、位置图标仍由 MyGo `ui` 包在 GPU 上以 Painter 路径自绘——它们承载资源管理器的视觉识别度，单色图标集无法替代。第三层是**真实画面**：图标视图里的图片/视频用解码出的缩略图，含媒体的文件夹用拼合封面（`thumb.go`），经 `ui.Image(...).Fit(ui.Cover)` 铺满方块；三层各有各的用意，媒体缩略图不是替代自绘图标，而是叠在它上面——解码未落地的那几帧显示的正是自绘图标。
- **Onevra 本地依赖**：`go.mod` 以 `replace` 指向本地克隆 `/Users/mcx/onevra/source`（含未发布的提交）；下一个 Onevra 版本发布后可移除该行。
- **删除语义**：删除是「移动到 `~/.Trash`」而非直接抹除，并在状态文件里记录来源路径，供还原与撤销使用。
- **剪贴板**：应用内实现（`clipPaths` / `clipCut`），不污染系统剪贴板；跨标签复制/粘贴可用。仅「复制为路径」写入系统剪贴板。
- **窗口**：无边框（`Frameless`），标题栏由应用自绘；窗口尺寸/位置不持久化（未用 MyGo 的 `StateKey`）。

### Go 媒体方案调研（为什么预览窗格这样实现）

在 `CGO_ENABLED=0`、纯 Go 自绘 UI 的硬约束下：

- **图片解码**：`ui.DecodeBitmap` 内置 PNG/JPEG/GIF/WebP/BMP（含 JPEG EXIF 方向）。纯 Go 扩展库有 `golang.org/x/image`（tiff 等）、`gen2brain/webp`、`gen2brain/avif`、`gen2brain/heic`（HEIC 无成熟纯 Go 解码器）。本项目取「能直接解的直接解，解不了的交给系统 Quick Look」——零依赖、格式覆盖最全。
- **视频播放**：纯 Go 没有通用视频解码器；可选方案全是 cgo 绑定或捆绑二进制。与 Explorer 行为对齐的正确姿势是：预览窗格显示海报帧 + 元数据，「打开」交给系统播放器。若未来内嵌播放，最优路径是 `Bitmap.Update(*image.RGBA)` + `ffmpeg` 子进程逐帧输出。
- **音频播放**：MyGo 自带 `audio` 包（注册 `audio/mp3`、`audio/vorbis` 解码器，macOS 经 purego 走 Audio Queue，无 cgo），覆盖 WAV/MP3/Ogg，内置播放器即基于此。
- **元数据**：`mdls` 与 `ffprobe` 都是进程调用，无链接依赖；缺失时预览自动降级，不影响主流程。

## 已知限制

- Windows 的 **Snap Layouts**（悬停最大化按钮弹出布局选择）未实现；ribbon、OneDrive、网络发现等高级功能未实现。
- `Ctrl+滚轮` 缩放图标不可用：MyGo 不向应用暴露原始滚轮事件（滚轮仅驱动滚动）；图标大小改用 `查看 > 放大图标 / 缩小图标`、`Cmd/Ctrl+Shift+=` / `-` 或 `Cmd/Ctrl+Shift+1..6` 切换。封面与缩略图依赖目录读取：网络卷或极深的目录里，首帧先显示自绘图标，解码落地后再换成画面。
- 视频海报帧优先 `ffmpeg`；macOS 缺失时回退 Quick Look，其他平台缺失时显示类型图标。
- 7z / rar 解压依赖 `7zz` 或 `unar`；tar.xz 依赖系统 `bsdtar`。
- 画廊的 HEIC / TIFF / AVIF 缩略图走系统 Quick Look，因此在 Windows / Linux 上这些格式只出现在列表里、没有画面（标准库能解的格式不受影响）。
- GIF 动画只在**空格快速预览**中播放；预览窗格与图标磁贴始终显示静态首帧，尽管插件卡片上的描述写的是「预览窗格与图标视图」。
- 磁盘健康的实时曲线与速率是**两次探测的差分**，精度受 3 秒轮询间隔与 SMART 计数粒度限制：它反映趋势，不是基准测试结果。
- 健康评分是应用自己的判据（见「磁盘健康」），不是厂商或系统的结论；它只解释已读到的指标，读不到的项不计分。
- 温度、寿命与计数依赖平台与硬件：Apple Silicon 由 `diskutil` 直接给出；Linux 与部分外置盘需要 `smartctl`，缺失时显示「未知」而不是猜一个数字。
- Windows 的 Storage cmdlet 不暴露 SMART 的累计读写字节，因此该平台的「累计读写」为「未知」。
- `qlmanage` 缩略图、`mdls` 元数据、`afplay` 音频兜底、`~/.Trash`、`/Volumes` 现全部经平台层（`platform.go` → `sys_darwin.go` / `sys_windows.go` / `sys_linux.go` / `sys_other.go`）分发，共享代码零平台分支。
